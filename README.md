# VI BASE Admin

[![Open Admin Panel](https://img.shields.io/badge/Open-Admin%20Panel-8b5cf6?style=for-the-badge)](https://konselitstudio.github.io/VI-Base-Admin/)

This repository contains only minified static assets for the VI BASE feed administration interface.

- Access requires an authorized Supabase account.
- Authorization is enforced by the backend Edge Function.
- No service-role key, password, admin allowlist, or push token is included.
- Source maps are intentionally not published.
